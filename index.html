Atlas

Atlas indexes repositories locally and returns focused, source-grounded context about symbols, callers, references, routes, and change impact through CLI, MCP, and HTTP.

GitHub · Download v0.1.43 · Benchmark data (JSON)

Get started

Install with brew install --cask aziron-ai/atlas/atlas or from the public npm registry with npm install -g @aziron/atlas. The installation guide also covers the authenticated GitHub Packages coordinate. Then run atlas index ., inspect readiness with atlas status, and preview assistant setup with atlas bootstrap --dry-run.

Headline results — Benchmark & Field Comparison — July 2026

  • Atlas F1 0.757 at 21.2 context tokens, mean across all 37 languages (fixture-truth, real-LLM scored, 222 cells / 666 model calls).
  • F1 1.000 at 27.1 tokens on the 28 fully-supported languages — full-file-dump accuracy at 6.1× fewer tokens.
  • Graph-tool comparison: 0.539 F1 at 97 tokens — Atlas delivers 6.4× the accuracy per token and 36× fewer query tokens.
  • Real repository (sirupsen/logrus, gopls call-hierarchy ground truth): Atlas F1 0.975 vs graph tool 0.084 vs raw file 0.017.
  • Query latency ~7.4 ms, flat from 15 to 39,161 symbols across 36 real repositories.
  • Corroborated by an independent Linux re-run: 37/37 languages fixture-perfect, 9× faster queries than the graph tool, gopls-truth F1 0.933.

Install

Homebrew: brew install --cask aziron-ai/atlas/atlas · npm: npm install -g @aziron/atlas · Linux: tar.gz / .deb / .rpm / .apk from releases. Then atlas index . and atlas mcp --transport stdio for agents.
